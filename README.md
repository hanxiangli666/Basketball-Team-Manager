# Drew Rangers · Tracker Pro

作者：Hanxiang Li。

沿用原来的绿色首页和手机 Bench 抽屉，保留 Practice 与 Game。界面恢复参考 `03481ea`（2026-07-18），比赛卡片按实际使用反馈持续调整；完整 Git 历史仍在。

## 在这台 Mac 上运行

需要 Node.js 22.12 或更高版本。

```sh
npm ci
npx wrangler d1 migrations apply drew-mbb-shared-game --local
npm run dev:full
```

检查与生产预览：

```sh
npm test
npm run build
npm run preview -- --host 127.0.0.1 --port 4173
```

完整本地地址：http://127.0.0.1:8788/ 。本机已设置被 Git 忽略的 `.dev.vars`；新机器需参照 `.dev.vars.example` 配置球队密码和随机会话密钥。`npm run dev` / `npm run preview` 是纯前端预览，Game 登录和同步需要上述完整服务。线上网站：[drew-mbb.com](https://drew-mbb.com)。生产静态文件在 `dist/`；GitHub `main` 分支由 Cloudflare Pages 项目 `drew-tracker-github` 自动构建发布。

## 使用

- 点击 Game 后输入球队密码。第一台登录的手机将本机现有比赛作为共享比赛并获得控制权，其他手机登录后只读查看。同一时间仅一台设备能调整时间、换人、伤病和比赛设置；查看手机可点 **Take control** 并确认接管，原设备随后变成只读。
- Game：确认首发前，场上五人按 **PG / SG / SF / PF / C** 排列；确认后按本次连续上场时间从高到低排列，再点 Start Clock。控制手机的启停、±1 秒、精确调时和换人先在本机立即执行，再后台同步。
- 默认首发：Eli Yusavage、Andre De Los Reyes、Charlie Thornton、Ben Manns、Dylan Napoleon。
- 界面使用单行简短称呼：通常只显示名字，重名显示 Charlie T / Charlie D；Ben Kipnis 为 **Kip**、Connor Jepson 为 **Jeppy**、Ben Manns 为 **B Manns**。Game、Bench、Ready、Total Time 和 Practice 使用同一套称呼；原始全名仍保留用于球员身份对应。
- 默认首发改变时，未开赛且没有计时记录的旧存档会自动采用新默认阵容。之后手动选择的阵容可以正常刷新保留；已开赛的比赛保留原阵容和时间。
- 换人：在 Bench 直接点球员整张卡片标记 **Ready**，可以标记多人。返回场上后，点对应下场球员的 **Swap** 完成一组换人；可点 Ready 名字切换下一位上场人。也支持先点场上的 **Sub out**，再点 Bench 中的上场人。
- 标记 Ready 不改变阵容、不开始计算上场时间；真正点击换人时才同时结算两人时间。场上五人按本次连续 **Game Time** 从高到低排列，时长相同则保持原先顺序。场上照片只用于辨认，不再弹出详情。可用 **Undo** 撤销最近的换人、调时或伤病标记。
- Bench 将 **20 个固定座位**按 PG / SG / SF / PF / C 排成五行，每行默认首发在最左，同位置替补在右侧。上场球员原格变灰、标记 **On court** 且不可点击；换下来恢复原格。顺序不随实际阵容、计时、关闭页面或刷新改变。
- 控制手机在 Bench 顶部点 **Injured** 后，可点场下球员标记 / 取消受伤，再点 Done 返回换人模式。受伤球员保留固定座位，用暗红色照片和 Injured 标签区分，正常换人时不可点击、不可加入 Ready；先下后上也不能换入。场上球员需先换下才能标记。伤病同步到其他手机，保留至手动取消，新比赛也保留。默认没有任何球员被标记受伤。
- Bench 已移除搜索框、位置筛选和长提示条，直接凭照片点选。手机竖屏和较矮横屏使用全屏替补页，五行按可用高度分配，在同一屏显示全部 20 人，无需上下滑动。先点场上 Sub out 时，标题显示 For 加下场人名字，Cancel 可以取消选择。
- Bench 照片铺满每格，底部显示单行称呼和累计时间，左侧固定的位置标签帮助找同位置球员。Ready 使用绿色描边和独立标签，选人、换人和待命人数变化都不会挤动格子。左上角菜单仍提供返回首页、换半场和新比赛。
- 顶部顺序为 **+1s / −1s / Confirm starters 或启停**，便于左手修正秒数。比赛时钟左侧的 **Total Time** 打开全队累计上场时间，包含全部 20 人，按累计时间从高到低排列。姓名使用 19–22px 粗体，位置和 On court 保留 10px 小字并下移。
- 场上五张卡片均分标题与底部 Bench / Undo 之间的可用高度，填满高屏的剩余空间。每张左侧为 **Sub out / Swap**，大号时间紧邻其右；名字和照片放在右侧，位置作为照片角标。照片随卡片增高、宽度最多 76px，铺满窗口并放大 20%；名字通常为 32–33px，接近 34–36px 计时数字，较窄卡片按实际可用宽度使用 26 / 24 / 22px，保持单行和原粗细。按钮随卡片变高且至少 44px。Bench 入口位于左下角，手机抽屉从左侧打开，关闭按钮也在左侧，便于左手操作。
- 场上卡片采用实心配色，常规为深森林绿；本次连续 Game Time 到 **3:00 变黄、4:00 变焦橙、5:00 变红**，持续保持对应颜色，不闪烁。姓名、时间、位置和按钮按卡片配色保持清楚对比。换人重新上场或手动修正时间后，颜色随当前时长更新。
- 点球员卡片上的大号 **Game Time** 可直接修改本次连续在场时长。分钟、秒钟分别用数字键盘输入；修正差额同步计入该球员的 Total Time，其他球员和比赛时钟不变。运行中编辑会继续计时，保存不会丢掉编辑期间经过的时间。
- 两个半场各 20 分钟，加时默认 5 分钟。第二半场恢复**第一半场实际确认过的首发五人**，不沿用上半场结束的五人；受伤首发留在 Bench，需另选替补。累计时间保留，连续在场时间归零。旧存档没有记录首发时使用配置的默认首发。加时沿用当前阵容，开始每次加时时可自由填写时长，允许超过 5 分钟。新比赛和切换半场有确认提示。
- 第一半场的左上角菜单提供 **Halftime**（比赛时钟运行时需先暂停）。独立深绿时钟页默认 15:00，支持开始、暂停、继续、重置及点击大时钟同步剩余时间。返回 Court 不会中断中场倒计时；刷新并登录后恢复中场页，后台经过的时间也会补算。中场期间比赛时钟和球员分钟数冻结，最后三分钟表盘变为金色，归零显示 Time to return，不自动开始下半场。点 End halftime / Set up 2nd half 并确认后，恢复首发并准备暂停的 20:00 下半场。查看手机随共享比赛自动进入 / 离开中场页。
- 计时使用时间戳差值，不累计定时器回调次数；显示按秒刷新。浏览器忙碌、切到后台或刷新后，会补算已过时间，最多到本节结束。离开前应按实际比赛情况停止计时。
- Practice：20 人固定在同一屏，手机使用四列，底部切换九个统计项目后，点球员整张卡片加 1。卡片大号数字为总分，小号数字为当前项目次数；得分后球员位置不移动。去掉大排行榜，顶部显示最高分，并列领先者全部高亮；全员 0 分时不选领先者。下方 **Undo** 可以逐次撤销最近 100 次计分，Reset 需确认；已有九项数据和上次选择的统计项目会在刷新后保留。
- 比赛仅保留时间和换人相关操作，不再显示导出、犯规统计或球衣号码。
- 顶部使用紧凑绿色计时面板、明确的启停主按钮和独立加减秒按钮。球员卡片根据可用高度伸缩，显示放大头像、Game Time 和位置；累计时间集中显示在 Total Time，预留手机上下安全区。

Vue 只负责界面，独立 JavaScript 计时模块位于 `src/game/session.js`。所有样式在构建时生成，不依赖外部 CDN。Game 登录和跨设备同步需要网络；控制手机短暂断网时仍可立即操作并暂存更改，重连后确认仍持有控制权再补传。Practice 继续完全本地运行。

## 数据与球员

Game 使用 Cloudflare Pages Functions 与独立 D1 数据库保存同一场共享比赛。客户端约每秒获取最新状态，用时间戳在各自手机上平滑计时，并校正设备时钟差。服务端检查登录身份、当前控制设备和版本号，旧设备或过期更新不能覆盖新数据。密码只在服务端秘密变量中验证，使用 HttpOnly / Secure / SameSite 会话 Cookie，错误尝试限流；源码和前端包不包含实际密码。生产需配置 `GAME_PASSWORD` 与随机 `SESSION_SECRET`，数据库绑定见 `wrangler.toml`，初始化迁移为 `migrations/0001_shared_game.sql`。

本机保留 Game 缓存、每个页面独立的待同步队列，以及首次同步前的 `drew.rotation.before-shared.v1` 旧比赛备份。断网后原设备重新接管前，若另一设备已经获得控制权，不会自动上传旧更改；未同步内容另存备份。Practice 仍仅保存在本机 `localStorage`，不会跨手机同步。首次使用共享比赛时，应先用实际计时手机登录，再让教练手机登录查看。

球员名单集中在 `src/data/roster.js`，照片在 `public/Photos/`。当前共 20 人：保留 12 名老球员，加入用户指定的 8 名新球员。七名已毕业球员及其不再使用的照片已移除。所有球员不显示球衣号码。2026-10-29 已按 [Drew 官方 2026–27 名单](https://drewrangers.com/sports/mens-basketball/roster/2026-27) 核对全队姓名，补齐 8 名新球员姓氏，并替换全部 20 张最新赛季头像。照片取自官方图片服务的 480px WebP 版本，保持完整比例、颈部和球衣上半身；保存在本地静态资源中，文件名包含内容指纹，更新后不会继续命中旧头像缓存。来源和校验值见 [照片来源记录](docs/roster-2026-27.json)。现有球员 ID、位置和默认首发保持稳定，旧比赛和训练统计仍对应原球员。

Admin、API key、AI 报告、犯规和导出功能继续移除。按新的比赛反馈恢复了简洁的 Injured 状态，并新增密码验证和共享比赛服务；旧数据库及其中的历史表没有修改。
